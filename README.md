# 🟢 Java for Beginners - Udemy Course Practice

This repository contains **practice code and exercises** for the Udemy course **"Java for Beginners"**. It covers the fundamental concepts of Java programming through hands-on examples and small projects.

---

## 🎯 Purpose

This repository is intended to:

- Provide **practical examples** for Java beginners.
- Reinforce understanding of **core Java concepts**.
- Demonstrate **object-oriented programming (OOP)** principles.
- Cover **threads, inner classes, abstraction, type casting, and wrapper classes**.
- Serve as a **reference and practice resource** for learning Java.

---

## 📚 Topics Covered

### 🔹 Core Java
- Variables & Data Types
- Type Casting
- Static methods & variables
- Static blocks

### 🔹 Object-Oriented Programming
- Classes & Objects
- Inheritance & Composition
- Abstract classes
- Anonymous classes
- Inner classes

### 🔹 Threads & Concurrency
- Thread creation
- Runnable interface
- Lambda-based threads
- Thread joining & sleep

### 🔹 Utilities
- Wrapper classes
- Exercises & small console apps

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/mhnuk2007/udemyjavaforbeginners.git
```

2. Open the project in **IntelliJ IDEA**, **Eclipse**, or **VS Code**.
3. Navigate to `src/`.
4. Run any class containing the `main` method.
